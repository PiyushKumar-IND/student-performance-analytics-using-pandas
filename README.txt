PANDAS STUDENT PERFORMANCE PROJECT

Files:
- dataset.csv: 20-student CSV dataset (clean starter data)
- students.json: first five student records in JSON format
- main.py: complete beginner project script
- charts/: folder where charts are saved

Setup:
1. Install Python.
2. Open this folder in VS Code.
3. Open the terminal in this folder.
4. Run: py -m pip install pandas matplotlib
5. Run: py main.py

The script explores, cleans, analyzes, exports and plots the data.
Note: dataset.csv is intentionally clean. You can add missing/incorrect/duplicate
values yourself to practise the cleaning section.
